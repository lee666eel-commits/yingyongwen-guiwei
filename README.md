# 应用文格式归位

把一篇**内容写对、格式全乱**的华文应用文，一步一步搬回作答纸上的正确位置——公函、通告、启事三种文体，共 17 篇范文，对准独中初三应用文考题。

**直接使用：** https://lee666eel-commits.github.io/yingyongwen-guiwei/

- 手机、电脑打开即可，不必安装
- 每一步说明格式规则和常见失分
- 最后显示内容（3322 红勾）、格式、语言、技术的评分

## 作者

林子策（Lim Zi Ce），马来西亚霹雳州华文独中华文教师。课件设计、范文与格式规则皆为原创。

## 自己生成

```
python build.py
```

- `范文.py`：全部范文（文体、题目、四段正文、署名）
- `engine.html`：归位动画引擎
- `build.py`：组装成单文件 HTML；组装前自动检查每篇红勾数是否 3／3／2／2、文中日期的星期是否正确

换上自己的范文即可生成新的课件。
